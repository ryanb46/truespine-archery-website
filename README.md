# truespine-archery-website
TrueSpine Archery: fitted arrows and bows, built to order. Pre-launch website.

**Live site:** https://ryanb46.github.io/truespine-archery-website/

## Run it locally

```bash
npm install
npm run dev
```

Then open the address it prints (http://localhost:5173/truespine-archery-website/).

## Built with
React, TypeScript, Vite, Tailwind CSS, shadcn/ui and React Router. Deployed to GitHub Pages by GitHub Actions.

## Email signups
The signup form runs in demo mode and saves nothing. To collect real signups, create a free Formspree form and add its ID as a repository variable named `VITE_FORMSPREE_ID` (Settings → Secrets and variables → Actions → Variables).
